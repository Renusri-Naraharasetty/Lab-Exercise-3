# Lab Exercise 3: Mobile UI Design Comparison

## AIM

To design and compare the mobile UI layouts of **Amazon, Flipkart, and Meesho** by creating user-friendly screens with consistent navigation, visual hierarchy, and interactive elements using Figma.

---

## ALGORITHM

1. Select Amazon, Flipkart, and Meesho as the case studies.
2. Study their existing mobile interfaces, features, and navigation.
3. Create separate mobile frames in Figma.
4. Design the Home page for each application with a search bar, offers, categories, and products.
5. Add promotional banners and product sections such as Deals, Top Offers, and Recommended Products.
6. Design suitable bottom navigation bars for easy movement between pages.
7. Apply UI/UX principles such as consistency, proximity, similarity, alignment, and visual hierarchy.
8. Use different brand-oriented layouts and typography while maintaining a simple and readable interface.
9. Connect important elements using Figma's Prototype feature.
10. Test the screens and compare the usability and visual design of all three applications.

# UI/UX PRINCIPLES USED

## 1. Consistency

Consistent buttons, icons, typography, spacing, and navigation patterns are used throughout the interfaces.

## 2. Proximity

Related elements such as product images, names, prices, ratings, and action buttons are placed close together.

## 3. Similarity

Similar products, categories, buttons, and navigation elements follow consistent visual patterns.

## 4. Alignment

Elements are properly aligned to create an organized and visually balanced interface.

## 5. Visual Hierarchy

Important elements such as product names, discounts, prices, offers, and call-to-action buttons are given greater visual importance.

## 6. Simplicity

The interfaces are designed to reduce unnecessary complexity and allow users to complete shopping tasks easily.

## 7. Feedback

Interactive elements provide visual feedback when users search, select products, add items to the cart, or navigate between screens.
